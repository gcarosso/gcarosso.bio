An agent run, visualized

One question, four agents, every claim traced to its source.

This is one complete run of a small multi-agent workflow. It follows the pattern Conclave coordinates: a lead delegates bounded tasks to specialists, the specialists call tools, and an independent reviewer checks the answer before it stands. The run came from a teaching harness I built to study that pattern, and it is simpler than Conclave. It uses Claude models only (Haiku 4.5 for the specialists and reviewer, Sonnet 5 for the lead), where Conclave routes across Claude, Codex, Gemini, and Grok. It adds one thing Conclave's job records do not have: every claim must quote the tool output it rests on.

How to read it

  • Timeline. One column per agent, time running down. Blue is a model turn, green a tool call, purple a delegation, red a failed call. Open any step to see its input and output.
  • Token bars. Where the reading and writing went. Here the trial specialist, not the lead, read the most.
  • The answer. Each paragraph ends in claim chips. Follow one to see the exact quote, highlighted inside the raw API response the harness saved.

PASS means every file matches its recorded hash, every paragraph cites a claim, and every quote occurs in its source. It does not mean the answer is complete or correct. A second run of the same question found a withdrawn trial (NCT02977689) that this run missed. Treat this page as an illustration of a workflow, not as a scientific assessment of IDH1.
